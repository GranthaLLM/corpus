# Spotcheck audits

Dated manual audits of individual corpus files, kept as a record of what was checked and found. They are snapshots, not a live issue tracker: an item may have been fixed after the audit date. Check the current file (and `git log`) before acting on an entry.

- `spotcheck/<work>.md` -- first-pass notes for each work.
- `shankara_*_audit.md` -- the 2026-10-09 sweep of the ten Shankara Upanishad tracks, merged and ranked in `shankara_upanishad_bhashya_flaws.md`.
- `bsb_shankara_mismatches.md` -- the matching sweep for Shankara's Brahmasutra bhashya.
